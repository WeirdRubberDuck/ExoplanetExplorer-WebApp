# Color Mapping & Glyph Modes

## Color Mapping

Numeric properties can be mapped with a **linear** or **logarithmic** scale. String properties use **categorical** mapping, assigning a color to each category from a set of default colors. You can change individual category colors, but those changes are not currently saved.

### Multiple Mappings

Ring glyphs can be colored by up to four different parameters, allowing for a detailed visual representation of the planetary system's properties. To apply multiple color mappings, click "Add variable" at the bottom of the Color mapping view.

## Glyph Modes

Glyph modes change how each planetary system is represented in the [Spatial Overview](/guide/basics/views#spatial-overview):

- **Ring:** Shows concentric rings, which can be colored by up to four parameters.
- **Star:** Adds a star glyph that can be colored by one parameter.
- **Inclination:** Shows planetary orbits at their inclinations as viewed from Earth. When the data is available, the glyph also shows the star's inclination and rotation axis. Planets without inclination data can use a default orientation and are shown with dashed orbits.

Star and Inclination modes can be combined, with separate color mappings for the planet ring and star.
